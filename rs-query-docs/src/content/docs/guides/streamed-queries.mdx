`streamed_query` is the port of TanStack's `streamedQuery` utility: the fetch closure returns a `Stream` of partial values instead of one future result, and the cache accumulates them into a single entry. Use it for server-sent events, chunked uploads, or any producer that emits progress.

## Define a streamed query

Wrap a stream-returning closure with `streamed_query`, then use the resulting value where a `Query` fetch closure goes:

```rust
use rs_query::{Query, QueryKey, StreamedQueryConfig, streamed_query};

let fetch = streamed_query(|_signal| async_stream {
    for chunk in chunks {
        yield chunk;
    }
})
.refetch_mode(StreamedQueryConfig::<Vec<LogLine>>::new().refetch_mode(rs_query::RefetchMode::Append));
```

<Aside type="note">
The exact stream combinator depends on your producer — any `Stream<Item = Result<T, E>>` works. The config's type parameter is the accumulated value type.
</Aside>

## Choose the refetch mode

When a refetch starts, existing cached data can confuse the accumulation. `RefetchMode` controls what happens to it:

| Mode      | Refetch behavior                                            |
| --------- | ----------------------------------------------------------- |
| `Replace` | Clear the cached data when the refetch starts (default)      |
| `Append`  | Keep old data; append the new stream's items after it        |
| `Reset`   | Reset to the configured `initial_value` when the refetch starts |

```rust
use rs_query::RefetchMode;

let cfg = StreamedQueryConfig::<Vec<LogLine>>::new()
    .refetch_mode(RefetchMode::Reset)
    .initial_value(Vec::new())
    .reducer(|acc: &mut Vec<LogLine>, item: LogLine| acc.push(item));
```

`.reducer(f)` customizes how each streamed item folds into the accumulator; the default appends. `.initial_value(v)` seeds the accumulator for `Reset` mode.

## Run it like any query

The wrapped value runs through `spawn_query`, `execute_query`, `ensure_query_data`, and the observers unchanged — the state machine, retries, and offline pausing all apply:

```rust
let query = Query::new(QueryKey::new("logs"), move || cfg_stream());
let handle = rs_query::spawn_query(&client, &query);
let state = handle.await;
```

Observers see intermediate states as the accumulator grows, so views render progress without extra code.
